How a project runs

Four stages. You see what’s done at each one before we move on.

  1. Talk it through

    You tell us the idea. We work out what it needs, and say so if a simpler option would do.

  2. Prototype

    A small working version you can try, so you’re reacting to something real.

  3. Build and test

    We build it properly in stages and test it, with regular updates on what works and what’s next.

  4. Launch and hand over

    It goes live, and you get everything you need to run it, plus support if something changes.
